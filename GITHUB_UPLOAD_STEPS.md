# 🗂️ Instructions for Project Upload

## Step 1: Create GitHub Repository
1. Go to: https://github.com
2. Click "New repository" (green button)
3. Repository name: `النسر-الدامي-Bloody-Eagle`
4. Description: `Islamic-Andalusian MMO Strategy Game - Complete Documentation`
5. Choose: Public (or Private if you prefer)
6. ❌ Do NOT add README or .gitignore (we have them already)
7. Click "Create repository"

## Step 2: After Repository Creation
Copy this URL from GitHub (you'll see it after step 1):
```
https://github.com/YOUR_USERNAME/النسر-الدامي-Bloody-Eagle.git
```

Replace YOUR_USERNAME with your actual GitHub username.

## Step 3: Run Commands in Terminal
In the project directory, run:
```bash
git remote add origin https://github.com/YOUR_USERNAME/النسر-الدامي-Bloody-Eagle.git
git push -u origin master
```

## Step 4: Verify
```bash
git ls-remote origin
```

You should see the remote branches and commits.
