## 🚀 خطوات رفع المشروع على GitHub

### الخطوة 1: إنشاء Repository جديد
1. اذهب إلى [GitHub.com](https://github.com)
2. انقر على **"New repository"** أو **"+"** ثم **"New repository"**
3. اسم Repository: `النسر-الدامي-Bloody-Eagle`
4. الوصف: `Islamic-Andalusian MMO Strategy Game - Complete Documentation`
5. اختر **Public** أو **Private** حسب تفضيلك
6. ❌ **لا تضيف** README, .gitignore, أو license (لدينا بالفعل)
7. انقر على **"Create repository"**

### الخطوة 2: رفع الملفات
انسخ الأوامر التالية في Terminal/Command Prompt:

```bash
# في مجلد المشروع
cd /path/to/النسر-الدامي

# إضافة remote repository (استبدل YOUR_USERNAME و REPO_NAME)
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

# رفع الملفات
git push -u origin master
```

### الخطوة 3: إعداد GitHub Repository
1. **Issues**: أنشئ issues للمهام
2. **Projects**: أنشئ مشروع لمتابعة التطوير
3. **Labels**: أضف العلامات (Labels) حسب دليل `GitHub_Labels_Creation_Guide.md`
