## 🔍 محتوى كل نظام

### نظام الوحدات (UnitBalance.cs)
- **أنواع الوحدات**: Infantry, Archer, Cavalry, Siege
- **نظام التفوق**: المشاة > الرماة > الفرسان > المشاة
- **المعاملات**: +30% هجوم، -25% دفاع
- **الدوال**: HasAdvantage(), GetDamageMultiplier()

### نظام الذكاء الاصطناعي (MinimaxLogic.py)
- **الخوارزمية**: Minimax للقرارات
- **الشخصية**: القائد أركان
- **الوظائف**: find_best_attack(), _evaluate_formation()
- **الميزات**: تحليل التشكيلات، اختيار الأمثل

### نظام بيانات اللاعب (PlayerProfileData.cs)
- **المعرفات**: PlayerID, PlayerName, PowerLevel
- **الموقع**: CastleLevel, CastleX, CastleY
- **الحماية**: HasShield, ShieldEndTime
- **الموارد**: Food, Wood, Iron, Stone, Gem
- **الجيش**: TroopCounts (Dictionary<UnitType, int>)
- **التحالف**: AllianceTag, AllianceRelationship

### نظام الاتصال العميل-الخادم
- **التكنولوجيا**: Unity C# + Python/Flask + MongoDB Atlas
- **البروتوكول**: UnityWebRequest (POST/GET)
- **الـ API Base**: /api/v1/
- **الملفات**:
  - **ServerManager.cs** - جسر الاتصال في Unity (UnityWebRequest + JSON)
  - **app.py** - خادم Flask (Minimax + endpoints)
- **النقاط الحرجة**: 
  - `/user/login` - إنشاء/تسجيل دخول اللاعب
  - `/user/update` - تحديث حالة اللاعب
  - `/combat/calculate` - حساب نتائج القتال بـ Minimax
