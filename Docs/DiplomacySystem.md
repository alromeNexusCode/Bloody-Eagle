# 🛡️ نظام الدبلوماسية والعلاقات (قلعة التآزر)

هذا الملف يحدد القواعد الرئيسية للتفاعل بين التحالفات على خريطة العالم.

## 1. تصنيف العلاقات (Relationship Tiers)

العلاقات يتم تعيينها يدويًا من قبل قائد التحالف (R4/R5) في قلعة التآزر، وتظهر كألوان مميزة حول قلاع أعضاء التحالف الآخرين.

| اللون | اسم العلاقة | الوصف والإجراءات المسموحة |
| :---: | :--- | :--- |
| **🔵 الأزرق** | **حليف العهد (Covenant Ally)** | **دفاع مشترك:** مسموح بإرسال تعزيزات (Reinforcements). غير مسموح بالهجوم أو التجسس. |
| **🟡 الأصفر** | **محايد/عدم ثقة (Neutral/Suspect)** | **حظر التجسس:** مسموح بالمرور عبر أراضي التحالف. غير مسموح بإرسال التعزيزات. (تظهر القلعة محصنة ضد التجسس العادي). |
| **🔴 الأحمر** | **عدو الدم (Blood Enemy)** | **حرب مفتوحة:** مسموح بالهجوم والتجسس. لا يمكن إرسال التعزيزات أو المساعدة. (تظهر القلعة محاطة بهالة حمراء). |

## 2. إجراءات الدبلوماسية الرئيسية

### 2.1 طلبات الدعم (Reinforcement Requests)
* **القاعدة:** لا يمكن إرسال دعم أو تعزيزات إلا للقلاع ذات العلاقة **"الزرقاء"** أو داخل أعضاء التحالف نفسه.
* **الحد الأقصى:** يتم تحديد الحد الأقصى للتعزيزات التي يمكن للقلعة استقبالها بناءً على مستوى **قلعة التآزر** الخاصة بها.

### 2.2 التجسس (Espionage)
* **القاعدة:** يمكن التجسس على القلاع ذات العلاقة **الحمراء** أو قلاع لا تنتمي لأي تحالف.
* **الحظر:** التجسس محظور على القلاع **الزرقاء** و **الصفراء** (يتطلب عنصر "رؤية الغدر" الخاص لكسر الحظر الأصفر).
