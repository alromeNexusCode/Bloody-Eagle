# 🦅 The Bloody Eagle Project (النسر الدامي)

## 🎯 ملخص المشروع
لعبة استراتيجية MMO للهواتف المحمولة تركز على القتال الشرس، التخطيط الاقتصادي المعقد، ونظام ذكاء اصطناعي متقدم (AI).
تم الانتهاء من وثيقة التصميم (GDD) بالكامل.

## ⚔️ الميزات الأساسية المعتمدة
* **نمو القلعة:** من C1 إلى C45 مع "جدار العروش" عند C30.
* **الذكاء الاصطناعي:** نظام "الحكمة الكامنة" لتحليل القتال (Minimax Logic).
* **القتال:** نظام "دورة الدم" (خسائر دائمة) و "صراع العرش".
* **الحماية:** "حجاب الصمود" (قابل للكسر بالهجوم).
* **الدبلوماسية:** تصنيف العلاقات (أزرق، أحمر، أصفر).

---

## 🛠️ خطة التطوير الرئيسية (5 مراحل)

### 1. المرحلة الأولى: النواة والأساسيات (MVP)
* **الهدف:** إطلاق نسخة قابلة للعب حتى C15.
* **الحالة الحالية:** تم إضافة أكواد التوازن والألوان.

### 2. المرحلة الثانية: الاقتصاد والاجتماع
* **الهدف:** تفعيل التحالفات والأسواق.
* **المحتوى:** قلعة التآزر، ممر الغدر.

### 3. المرحلة الرابعة: النهاية والصراع
* **الهدف:** تفعيل حرب العروش (قصر السيادة) وحرب الممالك.

---

## 👨‍💻 الخطوات التالية
* **التكنولوجيا:** Unity/Unreal Engine + Server Backend.
* **المهمة القادمة:** إضافة نموذج بيانات اللاعب (`PlayerProfileData.cs`).
