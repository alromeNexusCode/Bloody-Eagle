# 🏷️ دليل إنشاء تصنيفات GitHub - مشروع النسر الدامي

## نظرة عامة
التصنيفات (Labels) في GitHub تساعد في فرز المهام وتحديد أولوياتها ونوع العمل المطلوب لمشروع النسر الدامي.

## 📍 خطوات الوصول إلى إنشاء التصنيفات

### الخطوة 1: الوصول إلى تبويب القضايا (Issues)
- افتح متصفحك وادخل إلى صفحة مستودع مشروعك (The_Bloody_Eagle_Project)
- ابحث عن قائمة التبويبات الرئيسية في المستودع (مثل Code، Issues، Pull requests)
- اضغط على تبويب **Issues (القضايا)**

### الخطوة 2: الوصول إلى صفحة التصنيفات (Labels)
- بمجرد دخولك إلى صفحة القضايا (Issues)، ستجد في الجزء العلوي قائمة فرعية
- عادةً ما تكون هذه القائمة الفرعية تحتوي على خيارات مثل: **Open (مفتوحة)، Closed (مغلقة)، ثم Labels (التصنيفات)**
- اضغط على **Labels (التصنيفات)**

### الخطوة 3: إنشاء تصنيف جديد (New Label)
- في صفحة التصنيفات، ستجد زرًا بلون مختلف (عادةً أخضر أو أزرق) مكتوب عليه **New label (تصنيف جديد)**
- اضغط على **New label**
- ستظهر لك خانات لإدخال الاسم و الوصف و اختيار اللون

## 🏷️ التصنيفات المخصصة لمشروع النسر الدامي

### 1. تصنيفات النوع (Type Labels)
لتحديد طبيعة العمل (من المسؤول عن هذه المهمة):

| اسم التصنيف (Label Name) | اللون المقترح | الوصف |
|---|---|---|
| **Code: Client 💻** | أزرق فاتح | مهام برمجة الواجهة الأمامية (Unity/Unreal UI, Game Logic). |
| **Code: Server 🌐** | أزرق داكن | مهام برمجة الواجهة الخلفية (Database, Economy Calculations). |
| **Art: Graphics 🎨** | وردي | مهام الرسومات، تصميم المباني، الأيقونات، الواجهة الفنية. |
| **Design: GDD 📝** | أصفر | مهام تتعلق بتصميم اللعبة والموازنة (مثل موازنة C40). |
| **AI / Logic 🧠** | بنفسجي | مهام خاصة بخوارزمية الحرب (Minimax) ونظام الحكمة الكامنة. |

### 2. تصنيفات الأولوية (Priority Labels)
لتحديد أهمية المهمة وموعدها:

| اسم التصنيف (Label Name) | اللون المقترح | الوصف |
|---|---|---|
| **P0: Critical 🚨** | أحمر | مهمة تمنع إطلاق اللعبة أو توقف العمل (مثل خطأ في تسجيل الدخول). |
| **P1: High Priority** | برتقالي | يجب إنجازها في المرحلة الحالية (مثل دمج UnitBalance.cs). |
| **P2: Medium** | أصفر فاتح | يمكن تأجيلها لوقت لاحق في المرحلة (مثل إضافة الزخارف البصرية). |
| **P3: Low / Future** | رمادي | ميزات المرحلة التالية أو تحسينات (مثل آلات الحصار). |
