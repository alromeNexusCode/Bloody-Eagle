# 🎨 قائمة الأصول الفنية المطلوبة للمرحلة الأولى (MVP)

هذه قائمة بالأصول البصرية ذات الجودة المنخفضة (Low-Fidelity) المطلوبة لإطلاق النموذج الأولي القابل للعب.

## 1. أصول الواجهة (UI & Icons)

| الوصف | النوع | ملاحظات |
| :--- | :--- | :--- |
| **لوحة الألوان الأساسية** | Documentation | أكواد Hex للألوان الخمسة المعتمدة (الرمادي الداكن، الأحمر الدموي، الذهب). |
| **أزرار UI أساسية** | 2D/Sprite | تصميم زر مربع / مستطيل بخلفية معدنية داكنة (مظهر حديدي مطروق). |
| **شريط الموارد** | 2D/Sprite | شريط فارغ للتعبير عن شريط الصحة / شريط التقدم. |
| **الخطوط المعتمدة** | Font File | ملف خط واحد واضح للقراءة على الهواتف. |

## 2. أيقونات الموارد والوحدات

| الوصف | النوع | ملاحظات |
| :--- | :--- | :--- |
| **أيقونة الطعام** | 2D Icon | لحم بسيط أو عظم. |
| **أيقونة الحجر** | 2D Icon | صخرة رمادية بسيطة. |
| **أيقونة الفارس** | 2D Icon | خوذة فارس. |
| **أيقونة الرامي** | 2D Icon | سهم وقوس. |
| **أيقونة المشاة** | 2D Icon | درع وسيف. |

## 3. أصول العالم واللعبة

| الوصف | النوع | ملاحظات |
| :--- | :--- | :--- |
| **القلعة (Lvl 1)** | 2D/Sprite | رسم بسيط 2D أو نموذج 3D منخفض الدقة لعرين النسر. |
| **الخريطة (Tile)** | 2D/Sprite | رسم بسيط يمثل الأرض (مربع أخضر/بني). |
| **الخرائط الأساسية** | 2D/Sprite | 3-5 خرائط بسيطة للحروب الصغيرة. |

## 4. عناصر التفاعل

| الوصف | النوع | ملاحظات |
| :--- | :--- | :--- |
| **مؤثرات الحركة** | 2D/Sprite | أنيميشن بسيط للهجوم والدفاع. |
| **تأثيرات بصرية** | 2D/Sprite | دخان، شرر، تأثيرات دم بسيطة. |
| **أيقونات الرسائل** | 2D/Sprite | أيقونة تنبيه، رسالة، صمت. |

## ملاحظات هامة

### الأولوية
1. **أيقونات الوحدات** - ضرورية للعبة
2. **أزرار UI** - ضرورية للتفاعل
3. **الخرائط الأساسية** - ضرورية للقتال
4. **مؤثرات بصرية** - تحسن تجربة المستخدم

### المتطلبات الفنية
- **الدقة:** 512x512 بيكسل للأيقونات، 1024x1024 للخرائط
- **التنسيق:** PNG مع شفافية للواجهات
- **الحجم:** أقل من 50KB لكل ملف لضمان التحميل السريع

### الألوان المقترحة
- **الأساسي:** #2C2C2C (رمادي داكن)
- **الثانوي:** #8B0000 (أحمر دموي)
- **الذهب:** #FFD700 (للموارد القيمة)
- **الخلفية:** #1A1A1A (أسود داكن)
- **النص:** #FFFFFF (أبيض)

## الخطوات التالية
1. إنشاء الأصول بالترتيب المحدد أعلاه
2. اختبار الوضوح على شاشات الهواتف المختلفة
3. تحديث المجلد `Assets/Art/` في مشروع Unity
4. ربط الأصول بالسكريبتات المطابقة
