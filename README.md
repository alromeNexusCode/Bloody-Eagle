# 🦅 النسر الدامي - لعبة استراتيجية MMO

## نظرة عامة
"النسر الدامي" هو نموذج أولي (MVP) للعبة استراتيجية متعددة اللاعبين على الإنترنت، مبنية باستخدام Unity و Python/Flask. يركز النموذج الأولي على نظام القتال الذكي باستخدام خوارزمية Minimax.

## التقنيات المستخدمة
- **اللاعب (Client):** Unity Engine + C#
- **الخادم (Server):** Python + Flask
- **قاعدة البيانات:** MongoDB Atlas
- **الذكاء الاصطناعي:** خوارزمية Minimax للحسابات العسكرية
- **الاتصال:** HTTP/REST API + JSON

## البدء السريع

### متطلبات النظام
- Python 3.8+
- Unity 2021.3+
- MongoDB Atlas (حساب مجاني)

### تشغيل الخادم
```bash
cd Server/
pip install flask
python app.py
```

### تشغيل العميل
1. افتح مشروع Unity
2. استورد ملفات Client/
3. أضف ServerManager إلى مشهد اللعبة
