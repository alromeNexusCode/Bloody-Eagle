#### مكونات الـ PWA

##### 1. Service Worker
- **التخزين المؤقت**: cache للصفحات الأساسية
- **العمل بدون إنترنت**: تصفح أساسي بدون اتصال
- **التحديث التلقائي**: تحديث cache تلقائي
- **إشعارات Push**: للأخبار والتحديثات
- **Background Sync**: مزامنة البيانات
