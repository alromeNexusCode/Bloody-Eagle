# 🤝 Contributing to النسر الدامي (Bloody Eagle)

Thank you for your interest in contributing to the Bloody Eagle MMO Strategy Game! This document provides guidelines and information for contributors.

## 🎮 Project Overview

**النسر الدامي (The Bloody Eagle)** is a comprehensive Islamic-Andalusian inspired MMO strategy game with Mongolian architectural fusion. This repository contains complete documentation ready for development.

## 🚀 How to Contribute

### Current Status
The project is currently in the **documentation phase**. All major game design documents are complete and ready for development.

### Ways to Contribute

#### 1. **Development Contributions**
- **Unity Development**: Start with `Client/` scripts
- **Server Development**: Use `Server/app.py` as foundation
- **AI Implementation**: Develop `AI/MinimaxLogic.py` algorithms
- **Documentation**: Enhance existing documentation in `Docs/`

#### 2. **Art & Design**
- Visual concepts following the established art direction
- UI/UX mockups for Unity interface
- Audio concepts following the epic orchestral style
- 3D models for Islamic-Andalusian/Mongolian architecture

#### 3. **Content Creation**
- Game balance proposals
- New game mechanics ideas
- Narrative and lore development
- Marketing materials

## 🛠️ Development Setup

### Prerequisites
- Unity 2022.3 LTS or newer
- Python 3.11+
- Git

### Getting Started
1. **Fork** this repository
2. **Clone** your fork locally
3. Create a **feature branch** (`git checkout -b feature/AmazingFeature`)
4. Make your changes
5. **Commit** your changes (`git commit -m 'Add AmazingFeature'`)
6. **Push** to your branch (`git push origin feature/AmazingFeature`)
7. Open a **Pull Request**

## 📝 Pull Request Guidelines

### Before Submitting
- [ ] Code follows the existing style conventions
- [ ] Tests are added for new functionality
- [ ] Documentation is updated
- [ ] All tests pass locally
- [ ] Commit messages are clear and descriptive

### Pull Request Description
Include:
- **Clear description** of what your PR does
- **Related issues** (if applicable)
- **Screenshots/videos** for UI changes
- **Testing instructions** for reviewers

### Example PR Title
- `feat: Add new alliance diplomatic mechanics`
- `fix: Correct player resource calculation bug`
- `docs: Update building cost documentation`

## 🎨 Code Style

### Python (Server/AI)
- Follow PEP 8 style guidelines
- Use meaningful variable and function names
- Add docstrings for all functions and classes
- Maximum line length: 88 characters

### C# (Client/Unity)
- Follow Microsoft C# coding conventions
- Use PascalCase for public members
- Use camelCase for private members
- Add XML documentation comments

### Documentation
- Use clear, concise language
- Include examples where helpful
- Keep formatting consistent with existing docs
- Add diagrams for complex concepts

## 🐛 Reporting Bugs

### Bug Report Template
When reporting bugs, please include:
- **Operating system** and version
- **Unity version** (for client issues)
- **Python version** (for server issues)
- **Steps to reproduce** the bug
- **Expected behavior** vs **actual behavior**
- **Screenshots** or error messages
- **Console logs** (if applicable)

## 💡 Feature Requests

### Feature Request Template
For new features, please provide:
- **Clear description** of the proposed feature
- **Use case** - why is this feature needed?
- **Implementation suggestions** (if any)
- **Alternatives** you considered
- **Additional context** or mockups
