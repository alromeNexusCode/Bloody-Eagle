# 🦅 The Bloody Eagle Project (النسر الدامي)

## 🎯 ملخص المشروع
لعبة استراتيجية MMO للهواتف المحمولة تركز على القتال الشرس، التخطيط الاقتصادي المعقد، ونظام ذكاء اصطناعي متقدم (AI).
جميع تفاصيل التصميم (GDD) محفوظة في مجلد Docs/.

## ⚔️ الميزات الأساسية المعتمدة
* **نمو القلعة:** من C1 إلى C45 مع "جدار العروش" عند C30.
* **الذكاء الاصطناعي:** نظام "الحكمة الكامنة" لتحليل القتال (Minimax Logic).
* **القتال:** نظام "دورة الدم" (خسائر دائمة) و "صراع العرش".

---

## 🛠️ خطة التطوير الحالية (المرحلة 1: النواة)
* **الهدف:** إطلاق نسخة قابلة للعب حتى C15.
* **الحالة:** تم إضافة الأكواد الأساسية للتوازن والألوان والذكاء الاصطناعي.
* **المهمة القادمة:** إضافة نموذج بيانات اللاعب والمحتوى الفني.

---

## 📂 هيكل المستودع
* **`Docs/`**: وثائق التصميم التفصيلية.
* **`Client/`**: أكواد الواجهة الأمامية (C#, Unity).
* **`Server/`**: أكواد الواجهة الخلفية (الخادم).
* **`AI/`**: أكواد الذكاء الاصطناعي (Python/C#).
